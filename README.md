# ESTG-DigitalMarket 

**Plataforma Fullstack de Marketplace para Produtos Digitais e Serviços Freelance.**

Este projeto foi desenvolvido como parte do portfólio académico para a **ESTG (Escola Superior de Tecnologia e Gestão)**. O objetivo principal é demonstrar competências no desenvolvimento de uma aplicação web completa (Fullstack), focada na venda de infoprodutos e gestão de serviços digitais.
##  Sobre o Projeto
O **ESTG-DigitalMarket** permite que utilizadores se registem como compradores ou vendedores. Vendedores podem listar produtos (eBooks, PDFs, vídeos) ou serviços (programação, design), enquanto compradores podem navegar no catálogo, gerir um carrinho de compras e realizar checkouts simulados com download imediato.

## Tecnologias Utilizadas

### Frontend
- **HTML5 & CSS3:** Estrutura e estilização com design responsivo (Mobile-first).
- **JavaScript:** Lógica do lado do cliente e manipulação do DOM.
- **LocalStorage:** Persistência do carrinho de compras no navegador.

### Backend
- **Node.js & Express:** Ambiente de execução e framework para a API REST.
- **MongoDB & Mongoose:** Base de dados NoSQL e modelagem de dados.
- **JWT (JSON Web Token):** Autenticação segura e controlo de acessos (Roles).
- **Multer:** Gestão de upload de ficheiros digitais.
##  Funcionalidades Principais

### Para Clientes
- Catálogo de produtos com filtros e pesquisa.
- Carrinho de compras persistente.
- Checkout simulado com formulário de contacto.
- Download seguro de ficheiros após a "compra".

### Para Vendedores
- Registo e Perfil de vendedor.
- **CRUD Completo:** Criar, ler, atualizar e eliminar anúncios de produtos/serviços.
- Painel de controlo (Dashboard) para ver estatísticas simples de vendas.

### Sistema/Admin
- Autenticação de utilizadores.
- Proteção de rotas e ficheiros.
- Interface com Dark Mode toggle.
