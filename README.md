# DigitalMarket — Backend PHP + MySQL (phpMyAdmin)

Projecto académico ESTG-ESH (Instituto Piaget) — plataforma de e-commerce de produtos digitais e serviços freelance, agora com **base de dados real** em MySQL, API REST em PHP e autenticação JWT.

---

## 1. Requisitos

- **XAMPP** ou **WAMP** (PHP 8+ e MySQL/MariaDB)
- Browser moderno (Chrome, Firefox, Edge)

---

## 2. Instalação passo-a-passo

### 2.1 Copiar os ficheiros
Copia toda a pasta `digitalmarket` para dentro de `htdocs` do XAMPP:

```text
C:\xampp\htdocs\digitalmarket\        (Windows)
/Applications/XAMPP/htdocs/digitalmarket/   (Mac)
/opt/lampp/htdocs/digitalmarket/      (Linux)
